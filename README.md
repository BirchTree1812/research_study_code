# Overview

The goal of this project is to analyze the influence of the USA's tariffs on carbon dioxide per phones shipped. 
It will use Difference-in-Difference method, as well as the Carbon Rerouting index

# Data Cycle

## Obtaining the Data

Here is the data that I need for my project, with links to sources.

[sea-distances.org](sea-distances.org) - info on shipping distances.

[https://comtradeplus.un.org/](https://comtradeplus.un.org/) - United Nations' international trade database.

[https://www.imo.org/] (https://www.imo.org/) - International Maritime Organization's database on vessel emissions of CO2.
